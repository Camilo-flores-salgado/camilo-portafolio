# Camilo Flores — Portfolio

Personal portfolio built to show recruiters and hiring managers what kind of developer I am and how I work, in under 15 seconds.

**Live:** https://camilo-portafolio-rho.vercel.app

## Stack

- Next.js (App Router, static export)
- React + TypeScript (strict)
- Tailwind CSS
- Deployed on Vercel

  ## Highlights

  - 99/100 Lighthouse performance on mobile (LCP 2.0s, CLS 0)
  - Scroll-driven reveal animations using native CSS (animation-timeline: view()) and IntersectionObserver — no scroll-jacking, no animation library
  - Manual light/dark mode toggle with no flash of unstyled content
  - Full SEO/entity setup: JSON-LD, build-time OpenGraph image, sitemap, robots.txt

    ## Selected work featured on the site

    - Encuentro PyME Aconcagua — demo event landing with a working registration form (Cloudflare Worker + Resend), 100/100 performance
